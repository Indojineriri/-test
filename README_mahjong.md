# 🀄 麻雀 日程調整ツール

毎週の土日 × 昼/夜 の固定枠に対して、メンバーが ○/△/× を入力するだけで日程を
調整できる、月めくりカレンダー形式のツールです。

## 特長
- **月表示カレンダー**：土日のマスにだけ「昼」「夜」の枠が出ます。
- **タップで回答**：枠のボタンを押すたびに `－ → ○ → △ → ×` と切り替わります。
- **自動ハイライト**：○が必要人数（既定4人）以上そろった枠を緑＋✅で表示し、
  下部に「成立候補」として一覧します。
- **設定不要で動く**：GCSバケットを設定すれば全員で共有、未設定ならローカルの
  `data/mahjong.json` に保存します。

## 起動方法

```bash
pip install -r requirements.txt
streamlit run mahjong_app.py
```

ブラウザが開いたら、サイドバーで自分の名前を選択（初回は入力）して使い始めます。

## みんなで共有して使う（任意）
環境変数 `GCS_BUCKET` を設定すると、回答が GCS 上の
`mahjong/availability.json` に保存され、全員で同じ状態を共有できます。
Cloud Run へのデプロイ手順は既存の `deploy.sh` が参考になります
（その場合は起動コマンドの `app.py` を `mahjong_app.py` に変えてください）。

## データの保存場所
- GCS 設定あり：`gs://<bucket>/mahjong/availability.json`
- GCS 設定なし：`./data/mahjong.json`（`.gitignore` 済み）
